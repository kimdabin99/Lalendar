# Web UI Sandbox Copy

This folder is an isolated copy for personal UI work.

- Original app files are outside this folder.
- Edit files under `sandbox_web_ui/src` to avoid touching the shared source.
- The sandbox dev server uses port `5174`.

Run from this folder:

```bash
npm run dev
```

Main style file:

```text
sandbox_web_ui/src/styles.css
```
